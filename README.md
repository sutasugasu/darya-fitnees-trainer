# Сайт-карточка фитнес-тренера Дарьи Зубак

Одностраничный адаптивный сайт на HTML, CSS и JavaScript. Без платных библиотек и внешних шрифтов. Публикуется бесплатно через GitHub Pages.

## Перед публикацией

1. **Фото Дарьи.** Положите фотографию с именем `darya.jpg` рядом с `index.html`. Если файл называется иначе, измените `src="darya.jpg"` в блоке `ФОТО ДАРЬИ` внутри HTML. Подойдёт вертикальный портрет; изображение заполняет рамку без искажения пропорций. Если файл не найден, останется декоративная иллюстрация.
2. **Социальные сети и сообщение.** Внизу `index.html` найдите `const socialAccounts` и замените `YOUR_INSTAGRAM_USERNAME`, `YOUR_TELEGRAM_USERNAME`, `YOUR_VK_USERNAME`, `YOUR_MAX_USERNAME` и `7XXXXXXXXXX` на реальные username и номер WhatsApp. Username указывайте без `@`, номер WhatsApp — международный, только цифрами. Изменить готовое обращение можно в строке `const inquiryMessage`.
3. **Готовое сообщение.** Telegram и WhatsApp подставляют текст автоматически. MAX открывает экран отправки с готовым текстом, где нужно выбрать чат Дарьи. Instagram и VK не поддерживают надёжное универсальное автозаполнение текста в ссылке, поэтому текст дополнительно копируется в буфер обмена — его остаётся вставить в чат и отправить.
4. **Отзывы.** Замените шаблоны реальными отзывами и именами с разрешения клиентов.
5. **Цены в текущей версии:** персонально — 1 300 ₽ за занятие; «Дабл» — 900 ₽ на человека за занятие; «Трипл» — 700 ₽ на человека за занятие; план питания — 3 000 ₽ отдельно или в подарок при оплате тренировок. Убедитесь, что цены и условия указаны так, как договорено с тренером.

## Публикация на GitHub Pages

1. Войдите на [GitHub](https://github.com/) и создайте публичный репозиторий, например `daria-fitness`.
2. Загрузите `index.html`, `README.md` и фотографию `darya.jpg` через **Add file → Upload files**, затем выберите **Commit changes**.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. После публикации GitHub покажет URL сайта. Для репозитория `daria-fitness` он обычно будет вида `https://ВАШ-ЛОГИН.github.io/daria-fitness/`.
